# Maths-v1

A playful maths-themed music and quote microsite titled “Teacher: Maths is not Toxic.” The page pairs a short message with play and replay controls for its audio.

## Preview locally

Open `index.html` in a modern browser. Alternatively, run a local server from the project folder:

    python -m http.server 8000

Then visit http://localhost:8000.

## Audio and editing

The repository includes `your.mp3` as a local audio asset. Keep its filename aligned with the page reference if replacing the track. Browser autoplay rules may require the visitor to tap a control before audio starts.
