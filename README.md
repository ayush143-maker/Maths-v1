# Maths-v1

A playful maths-themed music and quote microsite titled “Teacher: Maths is not Toxic.” The page pairs a short message with play and replay controls.

## Preview locally

Open `index.html` in a modern browser, or serve the repository over HTTP:

    python -m http.server 8000

Visit http://localhost:8000.

## Audio and editing

The repository includes `your.mp3` as a local audio asset. Keep its filename aligned with the page reference if replacing the track. Browser autoplay rules may require the visitor to tap a control before audio starts.
