# Maths-v1

A playful maths-themed music and quote microsite titled “Teacher: Maths is not Toxic.” The single page in `index.html` pairs a short message with play and replay controls for the local audio asset `your.mp3`.

## Preview locally

Open `index.html` in a modern browser. Alternatively, run a local server from the project folder:

    python -m http.server 8000

Then visit http://localhost:8000.

## Audio and editing

Keep the audio filename aligned with the page reference if replacing `your.mp3`. Browser autoplay rules may require the visitor to tap a control before audio starts.
